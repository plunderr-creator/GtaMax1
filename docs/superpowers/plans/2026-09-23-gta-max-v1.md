# GTA Max v1 — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** Un serveur Node qui lit le chat TikTok à voix haute dans OBS et, à chaque cadeau, affiche une alerte et fait apparaître une voiture de police qui prend le joueur en chasse dans GTA V.

**Architecture :** Squelette copié de Final Max v0.3.0 (TikTok, TTS, HTTP/WS, config, persistance, lanceur), découpé en petits modules testables (`file-tts`, `gta-bridge`, `commandes-chat`, `evenements`, `persistance`, `roster`). Le jeu est piloté par un fichier-file (`gtamax_queue.txt`) que consomme un script ScriptHookVDotNet v3 compilé (`GTAMax.dll`). Spec : `docs/superpowers/specs/2026-09-23-gta-max-v1-design.md`.

**Tech stack :** Node 22.12 portable, `tiktok-live-connector` 2.4.0, `ws` 8.21.0, `dotenv` 17.4.2, `node --test` ; C# 5 compilé par `csc.exe` du .NET Framework 4.8 contre `ScriptHookVDotNet3.dll` (v3.7.0-nightly).
